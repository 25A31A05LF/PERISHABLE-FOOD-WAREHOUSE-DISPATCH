# Conclusion

The Perishable Food Warehouse Dispatch System was developed using Java and a custom Min-Heap data structure to manage perishable food inventory efficiently.

The project implements the First Expiry, First Out (FEFO) principle, giving priority to food batches with earlier expiry dates. It supports important warehouse operations such as adding batches, displaying inventory, identifying the earliest-expiry batch, dispatching food quantities, updating expiry dates and deleting expired batches.

The implementation of a Min-Heap helps perform insertion and extraction operations efficiently. The additional HashMap maintains batch positions and supports efficient lookup during expiry-date updates.

The application also provides dispatch simulation, near-expiry alerts, waste reports and file-based inventory storage.

Through this project, the practical application of Advanced Data Structures, particularly Min-Heap and HashMap, is demonstrated in a real-world inventory management scenario.

Overall, the system provides an organised approach to warehouse dispatch management and demonstrates how appropriate data structures can support timely food distribution and help reduce food wastage.
